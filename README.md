# Inflation Shield 
is an interactive Streamlit web application that calculates your personal inflation rate based on your expenses and compares it with the official Consumer Price Index.
# Key Features
Personalized CPI: Calculates a weighted inflation rate using your custom expense categories.

Global Data: Includes default inflation metrics for the United States (USD), Germany (EUR), and Japan (JPY).
Multilingual: Full support for English, German, and Japanese.

5-Year Projections: Interactive Plotly charts forecasting budget changes over 1, 2, 3, 4, and 5 years.

Detailed Breakdown: Summarizes expense allocation, budget percentages, and category-specific inflation rates.
